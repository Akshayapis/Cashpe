4️⃣ PAYMENT LINK + WALLET (2% commission)
=========================================================
payment-link.php:
- Form: amount, customer_name, customer_email (opt), customer_phone (opt),
  note, provider dropdown (only user's connected providers, max 3)
- Server-side check BEFORE generating:
    commission = amount * 0.02
    if (user.wallet_balance < commission) → block + toast "Insufficient balance"
- On success → Firestore payment_links/{id}:
  { link_id:"pl_...", uid, amount, commission, customer_name,
    customer_email, customer_phone, note, provider_id, upi_id,
    status:"pending", utr:null, created_at }
- Show link + Copy button + "Share on WhatsApp" (SVG icons)
- Links table below: all user's links with status badges

pay.php (public — PREMIUM UI):
- Glassmorphism card, gradient bg, Inter font
- CashPe logo (inline SVG), amount in 48px bold, merchant name
- QR code from: upi://pay?pa=UPI_ID&pn=Merchant&am=Amount&cu=INR
- "Open UPI App" deep-link button (SVG)
- AUTO-POLL every 3s → fetch('check_status.php?id=pl_xxx')
- On success → ✅ checkmark SVG animation + "Payment Successful" + UTR
- Failed → SVG X + retry
- Expired after 30 min → "Link expired" state

check_status.php:
- Load link → get provider + session_token
- cURL provider transaction API
- Match amount + UPI ID + timestamp within last 30 min
- If match:
    status = "success", utr = provider_utr
    wallet_balance -= commission  (deduct 2%)
    write wallet_transactions doc
    fire webhook_send.php (async)
- Return JSON { status, utr }

wallet.php:

- "Add Funds" → creates wallet_request doc (admin approves)
- Table: Date | Type | Amount | Description | Balance
- Warn banner if balance < ₹50

🔟 DEPLOYMENT (render.com)

Dockerfile:
  FROM php:8.2-apache
  RUN apt-get update && apt-get install -y libzip-dev libcurl4-openssl-dev \
      unzip && docker-php-ext-install zip curl
  RUN a2enmod rewrite
  COPY --from=composer:latest /usr/bin/composer /usr/bin/composer
  WORKDIR /var/www/html
  COPY . .
  RUN composer install --no-dev --optimize-autoloader
  RUN chown -R www-data:www-data /var/www/html
  EXPOSE 80

render.yaml:
  services:
    - type: web
      name: cashpe
      env: docker
      plan: free
      healthCheckPath: /ping.php
      envVars:
        - key: FIREBASE_CREDENTIALS_JSON
          sync: false
        - key: GOOGLE_CLIENT_ID
          sync: false
        - key: GOOGLE_CLIENT_SECRET
          sync: false
        - key: SMTP_HOST
          sync: false
        - key: SMTP_USER
          sync: false
        - key: SMTP_PASS
          sync: false
        - key: ADMIN_EMAIL
          sync: false
        - key: ADMIN_PASSWORD
          sync: false
        - key: COMMISSION_PERCENT
          value: "2"
